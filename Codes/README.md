# Source code

Code used in:

> E. G. Birgin, P. C. R. Ertel, R. S. Matos.
> *Using block coordinate descent for solving the close enough traveling
> salesman problem.* (journal and DOI to be added)

| Folder | Content |
|--------|---------|
| [`ILS_BCD_Fortran/`](ILS_BCD_Fortran/) | Iterated Local Search with BCD (Fortran 90), used in the ILS experiments of the paper. |
| [`BCD_Cpp/`](BCD_Cpp/) | BCD with the adaptive multi-start 1D Newton method for the visit points of a fixed visiting sequence (C++), used in the MA-CETSP-BCD experiments. |
| [`MA-CETSP-BCD/`](MA-CETSP-BCD/) | MA-CETSP with BCD (C++), used in the MA-CETSP-BCD experiments of the paper. |

See the README of each folder for build instructions, parameters and
examples.
